
# ArtArchive

**Student ID:** C243411

**Project Title:** Implementation of React Routing and Firebase Authentication Using React Router and Firebase.

## Project Description

ArtArchive is a React-based web application designed for art lovers. It allows users to explore an art platform with user registration, login, logout, and protected routes using Firebase Authentication.

## Technologies Used
- React.js
- React Router DOM
- Firebase Authentication
- CSS
- Vite

## Features
- Home Page
- User Registration
- User Login
- Dashboard
- Profile Page
- Logout Functionality
- Protected Routes
- Firebase Authentication

## How to Run the Project

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL in your browser.
